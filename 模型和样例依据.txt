1. 建议采用的模型与固定下载地址

MediaPipe 官方 Audio Classifier 概览推荐 YAMNet，521 个 AudioSet 声音事件类别。浏览器指南支持加载本地 modelAssetPath / modelAssetBuffer，音频由 classify(audioData, sampleRate) 处理。
官方指南：https://ai.google.dev/edge/mediapipe/solutions/audio/audio_classifier/web_js
官方概览：https://ai.google.dev/edge/mediapipe/solutions/audio/audio_classifier/index

固定版本模型下载 URL：
https://storage.googleapis.com/mediapipe-models/audio_classifier/yamnet/float32/1/yamnet.tflite
该精确地址见 Google AI Edge 官方演示源码的 defaultModelUrl 与 models.yamnet：
https://github.com/google-ai-edge/mediapipe-samples-web/blob/main/src/tasks/audio-classifier.ts
官方概览的 latest 下载地址为：
https://storage.googleapis.com/mediapipe-models/audio_classifier/yamnet/float32/latest/yamnet.tflite
建议用 /1/ 并记录最终下载文件的 hash，以免 latest 变化影响复现。

模型权重许可依据是 Google 官方 YAMNet 发布卡的 classification-tflite、Version 1 栏明确列出的 Apache 2.0：
https://www.kaggle.com/models/google/yamnet/tfLite
旧 TF Hub 精确模型卡入口会转向 Kaggle：
https://tfhub.dev/google/lite-model/yamnet/classification/tflite/1
发布卡说明该版本固定接受 15600 个 mono、16 kHz、float32 样本，返回 521 类分数；MediaPipe 概览写输入 1×15600。实际运行时应以下载的模型 metadata 和 SDK 结果为准，不混用任意长度波形的 SavedModel / 通用 TFLite 导出示例。本次未比较 Kaggle 与 MediaPipe 下载物的二进制是否完全相同。

原始模型代码/权重出处：
https://github.com/tensorflow/models/tree/master/research/audioset/yamnet
仓库 /research 的 Apache 2.0 许可：
https://github.com/tensorflow/models/blob/master/LICENSE
该 README 的 https://storage.googleapis.com/audioset/yamnet.h5 是 Keras 权重，不能当作浏览器 .tflite 直接使用。

结论：Apache 2.0 允许免费使用、修改及再分发，包含本地托管的部署方式。分发时附完整许可文本，保留适用版权/署名/许可及 NOTICE 信息；修改上游文件时注明改动。不能只凭 Google 文档页尾的“代码样例 Apache 2.0”来证明模型权重许可。本结论采用上述模型发布卡及原始仓库证据。
许可原文：https://www.apache.org/licenses/LICENSE-2.0

2. 浏览器运行时的实际版本与隐私说明

本轮主线程已下载 /private/tmp/mediapipe-tasks-audio-1.1.0.tgz，并解包到 /private/tmp/package/。本研究只读核验了该目录 package.json 与 README.md：name 为 @mediapipe/tasks-audio，version 为 1.1.0，license 为 Apache-2.0。网上搜索缓存仍曾显示 1.0.1 latest，不能拿缓存代替本地实际版本。应让 JS bundle 与 WASM 来自同一 1.1.0 包。
官方包入口：https://www.npmjs.com/package/@mediapipe/tasks-audio
运行时源码许可：https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE

实际 1.1.0 README 的 Privacy Notice 日期为 2026-06-05：输入内容在设备处理，MediaPipe 不向 Google 服务器发送该输入；另会发送 API 性能和使用指标，并提到开发者对必要的知情同意负责。本地托管 bundle/WASM/model 本身不证明没有指标网络请求。主线程拟用站点 CSP 限制外联，并在 About 如实披露；本研究没有验证最终 CSP、网络行为或离线可用性。
适合已知事实的文案：音频在浏览器本地分析，本站不上传录音；模型和运行库首次从本站下载。若写“没有任何外部请求”，须有最终浏览器网络验证证据。

4. 输出与许可注意点

官方模型标签列表：
https://storage.googleapis.com/mediapipe-tasks/audio_classifier/yamnet_label_list.txt

https://raw.githubusercontent.com/tensorflow/tfhub.dev/master/assets/docs/google/models/yamnet/1.md

仅采用 IBM 的上述两份已核验音频，不顺带复制整个 samples 目录：其它文件许可各异（含 Sampling+ 等）。IBM 的 class_labels_indices.csv 另标 CC BY-SA 4.0，本项目无需复制该文件。将应用代码许可与 Apache 模型/运行时、CC0 鸟鸣、CC BY 4.0 雨声分别注明。
